# MS Temp Mail — Complete UI Inventory

Full structured inventory below. All requested files read in full.

## main.jsx (`client/src/main.jsx`)
- **Type**: utility (entry + ErrorBoundary)
- **Purpose**: React root mount. Wraps `<App/>` in `<React.StrictMode>` and an inline `ErrorBoundary` that catches render errors and shows a Turkish fallback screen so the user never sees a black screen.
- **Visible elements / layout**: Full-viewport centered error card: gradient bg (`radial-gradient(circle at top, rgba(59,130,255,0.12), transparent 35%), linear-gradient(180deg, #060d1f 0%, #040918 100%)`), 56px warning tile (`⚠️`), `Bir hata oluştu` title, error message text, `Sayfayı Yenile` button.
- **Key state**: `hasError`, `error`.
- **Interactions**: Button reloads page via `window.location.reload()`.
- **API calls / data**: none.
- **Renders/contains**: `<App/>`.
- **Where it's shown from**: ReactDOM root (`#root`).
- **Design notes**: Inline-styled (not Tailwind). Font `Plus Jakarta Sans`. Blue→cyan gradient icon tile, `#9ab0d3` muted text, blue gradient button with glow. Turkish hardcoded.

## App.jsx (`client/src/App.jsx`)
- **Type**: scene (root shell)
- **Purpose**: Top-level app. Auth-gates UI, hash routing (`#/inbox`, `#/domains`, `#/account`, `#/bulk`, `#/automation`, `#/docs`, `#/admin`, `#/admin-bulk`, `#/bulk-inbox`), wires Socket.io realtime, polling fallback, notification sound, toast system, lazy-loads heavy scenes.
- **Visible elements / layout**: Sticky `app-header` (logo `MS Temp Mail`, brand subtitle, xl nav-pills, user menu/avatar or Sign in/Sign up buttons), `workspace-frame` with left `workspace-rail` (desktop sidebar nav) and `app-main` content area, mobile bottom `mobile-workspace-nav`, footer (`MS Temp Mail • Dev: Emir Han Mamak • Mamak Studio`), toast bubble, modals (password required, set password, compose, pro request, bulk inbox), auth overlay.
- **Key state**: `page`, `bulkInboxPool`, `addr`, `domains`, `emails`, `selected`, `loading`, `refreshing`, `error`, `notif`, `compose`, `sending`, `sockOn`, `pwModal`, `pwInput`, `pwErr`, `spwShow`, `spwVal`, `proReqShow`, `proReqMsg`, `history` (localStorage `tm-history`), `showUserMenu`, `showAuth`, `authMode`, `notificationSound` (localStorage `tm-notification-sound`).
- **Interactions**: Nav clicks (`navigate()`), user menu open/close (outside-click), sign in/up, copy address, copy OTP, refresh, random, generate, open address (with password modal fallback), set password, compose reply, send mail, delete mail, pro request, open account settings, logout, open bulk inbox pool modal.
- **API calls / data**: `GET /api/addresses/domains`, `POST /api/addresses/random`, `POST /api/addresses`, `GET /api/addresses/:address`, `POST /api/addresses/set-password`, `GET /api/emails/:address?limit=100&order=desc`, `GET /api/emails/single/:id`, `DELETE /api/emails/:id`, `POST /api/emails/send`, `auth.requestPro`. Socket.io `subscribe` to `addr.address`, listens `new-email`.
- **Renders/contains**: `AddressBar`, `Inbox`, `EmailView`, `AccountPanel`, `Modal`, lazy `AuthPage`, `AdminPanel`, `BulkStudio`, `BulkInbox`, `AdminBulkStudio`, `AutomationCenter`, `DocumentationCenter`.
- **Where it's shown from**: root mount.
- **Design notes**: Dark-first `app-shell` grid overlay + 3 blurred gradient blobs (purple/cyan/blue). Nav pills (`nav-pill`, `nav-pill-active`). Toast color-coded green/red/blue. Beep on new mail via `useBeep` + `playNotificationSound`. `LocaleProvider` wraps shell. Bulk Inbox pool opens in `size="full"` Modal. `bulk-inbox` hash auto-redirects to `bulk`.

## i18n.js (`client/src/i18n.js`)
- **Type**: utility (i18n provider)
- **Purpose**: Minimal homegrown i18n. Exposes `LocaleProvider`, `useLocale()`, `createTranslator(language)`, `normalizeLanguage(language)`. Supports `tr` (default) and `en`. Keys grouped under `app`, `addressBar`, `account`, `accountModal`, `auth`.
- **Key state**: context `LocaleContext` with `{ language, t }`.
- **Interactions**: `t(key, vars)` returns string with `{token}` interpolation; falls back to `tr` then to the key itself.
- **API calls / data**: none.
- **Renders/contains**: provider only.
- **Where it's shown from**: `App.jsx` wraps shell in `<LocaleProvider language={language}>`.
- **Design notes**: Non-React deps; uses `createElement`. `tr` is source of truth; `en` partial overlay.

## useAuth.js (`client/src/hooks/useAuth.js`)
- **Type**: hook
- **Purpose**: JWT auth state machine. Persists token in `localStorage('tm-token')`, loads `/api/auth/me` on mount, exposes guest fallback (`GUEST_USER`, `GUEST_PACKAGE`, `GUEST_STATS`) and all auth actions.
- **Key state**: `user`, `token`, `pkg`, `stats`, `preferences`, `loading`. Derived: `isGuest`, `isAdmin`, `isPro`, `isProPlus`, `isFree`, `currentPackageName`.
- **Interactions**: `register`, `login`, `logout`, `requestPro`, `updateProfile`, `requestEmailChange`, `confirmEmailChange`, `updatePreferences`, `changePassword`, `uploadAvatar`, `loadMe`.
- **API calls / data**: `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me`, `POST /api/auth/request-pro`, `PUT /api/auth/me`, `POST /api/auth/request-email-change`, `POST /api/auth/confirm-email-change`, `PUT /api/auth/preferences`, `POST /api/auth/change-password`, `PUT /api/auth/profile-photo`.
- **Renders/contains**: none.
- **Where it's shown from**: `App.jsx` (`const auth = useAuth()`).
- **Design notes**: Guest package caps: 3 addresses, 50 emails, 7-day retention. Defaults theme `system`, language `tr`, sound `chime`.

## apiFetch.js (`client/src/utils/apiFetch.js`)
- **Type**: utility
- **Purpose**: Thin `fetch` wrapper auto-unwrapping `{ success, data, error, message }` envelope. Returns Proxy over Response so `.json()` resolves to unwrapped payload; other Response methods pass through.
- **Interactions**: `apiFetch(input, init)` — drop-in `fetch` replacement.
- **API calls / data**: all of them.
- **Renders/contains**: none.
- **Where it's shown from**: `App.jsx`, `AccountPanel`, `AdminPanel`, `BulkStudio`, `BulkInbox`, `AdminBulkStudio`, `AutomationCenter`.
- **Design notes**: Exports `unwrapEnvelope` too (used by `AccountPanel` and `AdminPanel` for raw `fetch` paths).

## notificationSound.js (`client/src/utils/notificationSound.js`)
- **Type**: utility
- **Purpose**: Synthesizes 6 notification sounds via WebAudio oscillators (no audio assets). Exposes `NOTIFICATION_SOUNDS` list and `playNotificationSound(audioContext, soundId)`.
- **Sounds**: `classic` (Classic Ping, default fallback), `soft` (Soft Bell), `digital` (Digital Pop), `chime` (Glass Chime, app default), `alert` (Alert Pulse), `arcade` (Arcade). Each uses `osc.type` sine/triangle/square/sawtooth with gain envelopes.
- **Where it's shown from**: `App.jsx` (`useBeep`), `AccountPanel`, `AdminPanel` (preview).

## App Shell & Navigation (`App.jsx`)

**Top-level routing**: Hash-based. `page` state initialized from `window.location.hash.replace('#/', '')` (default `inbox`). `navigate(nextPage)` pushes `#/nextPage` to history and sets `page`. `popstate`/`hashchange` listeners sync `page`. `bulk-inbox` hash auto-redirects to `bulk` (legacy link compat — Bulk Inbox now opens as a Modal popup).

**Views** (rendered in `app-main` via conditional `page ===`):
1. `inbox` — `AddressBar` + `Inbox` + `EmailView` in 2-col grid (`xl:grid-cols-[minmax(320px,0.82fr)_minmax(0,1.7fr)]`).
2. `domains` — static card listing active domains with wildcard badges.
3. `account` — `AccountPanel`.
4. `bulk` — `BulkStudio` (non-guest). `onOpenPool` sets `bulkInboxPool` → opens `BulkInbox` in `Modal size="full"`.
5. `automation` — `AutomationCenter` (non-guest) or guest `ops-empty` prompt.
6. `docs` — `DocumentationCenter`.
7. `admin-bulk` — `AdminBulkStudio` (admin only).
8. `admin` — `AdminPanel` (admin only) or `Admin yetkisi gerekiyor` card.

**Navigation UI**:
- Header (sticky, `app-header`): logo + `MS Temp Mail` + brand subtitle; xl-only nav-pills row (Inbox/Domains/Bulk/Otomasyon/Dokümanlar/Admin); right side guest Sign in/Sign up OR user avatar (gradient circle or img) + name + role label + ChevronDown → user menu (Hesap Ayarları, Admin Paneli, Pro'ya Geç, Çıkış Yap).
- Left `workspace-rail` sidebar (lg+): Inbox/Domainler/Bulk Studio/Otomasyon/Dokümanlar/Hesap + admin divider + Operasyonlar/Bulk yönetimi. Active `is-active` (white on blue).
- Mobile bottom `mobile-workspace-nav` (lg-): Inbox/Domain/Bulk/Akış/Docs/Hesap icons.

**Auth gating**: `auth.loading` → centered loading screen (Mail icon + `Yükleniyor...`). `showAuth` overlay renders lazy `AuthPage`. `auth.isGuest` hides Bulk/Automation from nav. `auth.isAdmin` reveals Admin entries.

**Locale/i18n**: `language = normalizeLanguage(preferences?.language || user?.language || 'tr')`. `t = createTranslator(language)`. Entire shell wrapped in `<LocaleProvider language={language}>`. `document.documentElement.lang` and `colorScheme` set via effect.

**Theme**: `theme = preferences?.theme || user?.theme || 'system'`. Effect resolves `system` to `light`/`dark` via `matchMedia`, sets `data-theme` on `<html>`. Light theme has extensive CSS overrides.

**Notification sound**: `notificationSound` state (localStorage `tm-notification-sound`, default `chime`). `useBeep(soundId)` hook lazily creates `AudioContext` on first user click/keydown (autoplay-policy unlock), exposes `init`/`play`/`preview`. `handlePreviewNotificationSound(soundId)` sets state + previews. Sound played on `new-email` socket event.

**Beep on new mail**: Socket.io connection when `auth.user` present. On `new-email`, payload unwrapped, email prepended (dedup by id), toast `app.newMailToast` shown, `playBeep()` called.

**Realtime & polling**: Socket.io with `transports: ['websocket','polling']`, reconnection. `subscribe` emitted with `addr.address` whenever `addr` changes. Polling fallback: if `!sockOn`, `loadEmails()` runs on `pollDelayRef` timer starting at 5s, doubling on failure up to 60s, reset to 5s on success.

**Address lifecycle**: On `auth.user`, loads domains + restores last address from `localStorage('tm-last-addr')`. If no saved address and domains loaded, auto-generates random. Address changes persist to `tm-last-addr` and push to `tm-history` (max 20).

**Toasts**: `toast(msg, type)` sets `notif` with 3.5s auto-clear. Rendered top-right `fixed top-24 right-6 z-[100]`, colored green/red/blue, `animate-slide-down`.

**Modals mounted at shell level**: Password Required (address open with password), Set Password, Compose (New Mail, `wide`), Pro Request, Bulk Inbox (`size="full"`).
