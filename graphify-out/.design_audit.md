1. **Two theming mechanisms fighting**: Tailwind `darkMode:'class'` configured but app uses `data-theme` attribute → `dark:` variants never fire; theming done via `[data-theme=light]` CSS overrides padded with `!important`.
2. **Three nav systems** (header pills / workspace rail / mobile nav) hand-maintained with divergent labels and route sets.
3. **Four "card" patterns** with four radii and three shadow systems.
4. **Two animation systems** (CSS `@keyframes` + Tailwind `keyframes` config) with duplicated `slideUp`/`slideDown`.
5. **i18n covers ~25% of UI** — only AddressBar/Account/Auth/App shell. Admin, Email, Bulk, Automation, Docs, Inbox, Modal, main.jsx error are hardcoded Turkish.
6. **Accent tokens not redefined for light** → light theme relies on `!important` patches in components that hardcoded dark assumptions (text-white, bg-white, bg-black classes).
7. **Charts hardcoded hex** (`CHART_COLORS`, recharts `contentStyle`) — not theme-aware, dark-only.
8. **Hardcoded dark hex in gradients/bgs** across `index.css`, `main.jsx`, `Modal.jsx` (`#060d1f`, `#040918`, `#161616`, `#0A1329`, `#091326`) — none reference tokens.
9. **AdminPanel = 2457-line single file**, 34 useState, 8 tabs, recharts, DNS docs builder, subdomain CRUD — no subfile split.
10. **Inconsistent breakpoints**: Tailwind `sm/md/lg/xl` in JSX + raw `px` media queries (`1023/1279/1120/1100/820/720/480`) in CSS, no shared scale.
